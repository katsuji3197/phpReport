# phpReport

PHP と MySQL で商品の一覧、カート、注文を扱うアプリケーションです。データベースへの接続情報は、ソースに直接書かずプロジェクト直下の `.env` から読み込みます。

## 必要な環境変数

`model/dbconnect.php` が `.env` を `parse_ini_file` で読みます。シェルに export した環境変数ではなく、このファイルのキーを使います。

| キー | 用途 | 取得方法 |
| --- | --- | --- |
| `DB_HOST` | MySQL のホスト名 | 同じマシンで動かす場合は `localhost`。Docker やレンタルサーバの場合は、そのサービスの接続先ホスト名 |
| `DB_NAME` | 接続するデータベース名 | MySQL 上に作成したデータベースの名前 |
| `DB_USER` | 接続に使う MySQL ユーザー名 | `CREATE USER` で作ったユーザー名、またはホスティングの管理画面に表示されるユーザー名 |
| `DB_PASSWORD` | そのユーザーのパスワード | MySQL ユーザー作成時、または管理画面で設定したパスワード。リポジトリやドキュメントには書かない |

キー名とダミー値だけの雛形が `.env.example` です。実際の接続情報は含めません。

## `.env` の作り方

1. PHP（PDO MySQL）と MySQL を用意する。
2. 接続用のデータベースとユーザーを MySQL 側で作成する。
3. 雛形をコピーする。

```bash
cp .env.example .env
```

4. `.env` を開き、上の 4 つのキーを手元の接続情報に書き換える。
5. `.env` は `.gitignore` により Git の管理対象外です。`git add` してもコミットされません。

## データベースの初期化

スキーマとサンプルデータは `migrate.sql` です。`.env` に書いた接続先へ、MySQL クライアントから投入します。

```bash
mysql -h <DB_HOST> -u <DB_USER> -p <DB_NAME> < migrate.sql
```

サンプル会員の `login_pass` は空です。パスワードはリポジトリに置いていないので、投入したあとに使う会員だけ、ローカルのデータベース上で設定してください。
